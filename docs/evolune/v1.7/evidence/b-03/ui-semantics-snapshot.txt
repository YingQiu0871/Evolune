## accessibility contract
- every metric row is a real Text pair (label + count) AND carries
  contentDescription = stringResource(R.string.insights_bar_description, label, count)
- range chips expose Material selected semantics (asserted by InsightsScreenTest)
- no colour-only / icon-only / geometry-only carrier exists (no chart, no progress metric)
- fontScale 1.5f smoke covered by an @Preview and by InsightsScreenTest
