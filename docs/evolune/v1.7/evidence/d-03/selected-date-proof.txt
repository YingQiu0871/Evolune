  - CONTENT <-> EMPTY_DAY switching without re-read (TR10/TR11)
  - empty selected date    -> neutral EMPTY_DAY, no adherence semantics (TR7/HC7)

  combination test (active A; pending load B; selectDate inside B's month; B executes and
  publishes the latest valid B selection with NO extra source read from selectDate)

   valid selected-date intent — it requires a valid selection or a new load context."

creates a read generation; valid in-flight selections update the intent only.
