# PK 2.0 第 5b 片：个人清除率拟合与化验时间加权评估

状态：评估结论（2026-10-04）。本文只给出结论与建议，不改代码；是否做成功能由维护者决定。

## 1. 问题

第 4、5a 片只拟合一个个人**幅度**系数：整条 E2 模型曲线乘以同一个数。
如果某人清除雌二醇比模型快或慢，真实曲线的**形状**会不同（谷浓度变化比峰浓度大），
单一幅度系数无法表达。本片评估两件事：

1. 能否从用户的少量化验中可靠地拟合个人清除率（即 E2 消除速率常数 k3 的个人倍数）；
2. 是否需要按化验时间加权（较新的化验权重更高）。

## 2. 方法

- 模型：生产 `SimulationEngine` 与 `ParameterResolver` 的副本，只把 k3 乘以一个倍数 m，
  其余参数不变；体重 60 kg。
- 参数：ln 幅度 a 与 ln 清除倍数 c，两者先验均为 N(0, 0.5²)，与第 1 片 τ = 0.5 一致；
  化验误差在对数空间 σ = 0.13，与第 1 片一致（σ/τ 来源与待审阅状态见计划 §3.2）。
- 在稳态给药方案下，对不同的化验时间组合计算 Fisher 信息矩阵（数值求 ∂lnC/∂ln m），
  得到 c 的后验标准差 sd(ln k) 以及 a 与 c 的相关系数。先验 0.5 意味着"不做拟合"；
  sd 越接近 0.5，化验提供的信息越少。
- 另算：真实清除快 30%（m = 1.3）时，各化验时刻真实值与模型值之比。
  比值在不同时刻差别越大，只拟合幅度造成的形状误差越大。

这是局部线性化的可辨识性评估，不是对真实人群数据的验证。

## 4. 结论

1. **清除率只能部分辨识。** 单次化验无法区分"吸收多/清除慢"和"整体偏高"：
   相关系数 0.91–0.98，c 的不确定度只比先验缩小有限。
2. **只有在给药周期不同阶段采多次血时才有意义。** EV 峰 + 谷可把 sd 从 0.5 降到 0.20；
   口服 4 小时 + 谷降到 0.14，三次降到 0.11。同一阶段重复采血（两次谷、贴片两次）几乎没有增益。
3. **EC 与贴片基本不可辨识**（sd 0.32–0.36）：EC 曲线在模型中很平缓，贴片是近似恒速释放，
   清除率变化几乎只表现为整体缩放，与幅度系数无法区分。
4. **只拟合幅度的误差在有峰谷差的方案中确实存在**：清除快 30% 时，EV 谷比峰多偏低约 13 个百分点，
   口服谷比 4 小时多偏低约 20 个百分点。不过此时现有校准说明里的拟合误差（`fitErrorPct`）会变大，
   用户能看到"化验之间不一致"，不会被静默掩盖。
5. 现实中用户多数只在谷值采血，且采血时刻记录精度有限（口服尤其敏感），
   这会进一步削弱上表中按理想时刻算出的信息量。

## 5. 时间加权

未做数值评估，以下为推理：

- 模型已经按完整用药记录计算每次化验时刻的预测值，剂量、途径、间隔的变化都已反映在预测中，
  不需要靠降低旧化验权重来"追上"方案变化。
- 时间加权真正要处理的是个人参数本身随时间漂移（体重、肝功能、合并用药等）。
  在现有数据量（通常几次到十几次化验）下，加权会让系数更容易被最近一两次化验带偏，
  而单次化验误差（σ = 0.13，约 ±13%）并不小。
- 一个更直接的替代是让用户删除或停用不再代表现状的旧化验，这在第 3 片的录入界面中已经可以做到（删除）。

## 6. 建议

- **暂不实现清除率拟合。** 对最常见的"只测谷值"用法几乎没有收益，对 EC 和贴片没有收益，
  却会让校准逻辑和说明更难理解，并依赖用户精确记录采血时刻。
- **暂不实现时间加权**，保持第 4 片的等权拟合。
- 若以后要做，前提与范围：
  1. 先完成 σ/τ 的独立科学审阅（计划 §3.2）；
  2. 仅在同一途径下存在至少两次、处于给药周期不同阶段的化验时才启用，否则退回只拟合幅度；
  3. 只对注射 EV 与口服/舌下这类峰谷明显的途径启用；
  4. 说明卡片需要额外展示清除倍数及其不确定度，仍标注为模型估算。
- 可以低成本做的改进（未排期）：当拟合误差较大时，在说明卡片里提示"化验之间差异较大，
  可能与采血时间记录或个人代谢差异有关"。
