Observed results: all six fixes behave as specified on the physical device. No crash, no
flicker-restart, no data mutation during the walkthrough (navigation / range switching /
inspection only; zero-write behavior unaffected). The debug build emits a "发现新版本"
prompt because the store lists the v1.7.0 release — unrelated to this hotfix.

Honest deviations
  - The hotfix premise said Settings shows collapsed/accordion entries; the shipped v1.7.0
    tree was already a flat list. The factual gap was the missing separate 隐私与权限 entry
    (previously merged into the 指南 title). The hotfix adds that entry and keeps the flat
    presentation; no accordion code existed to remove.
  - The acceptance device had no prior Evolune data, so 20 test intakes were imported
    through the shipped import path to make the factual surfaces meaningful. No device data
    was modified beyond that.
  - The temporary debug install and seeded test data remain on the device for inspection;
    /sdcard scratch files used during automation were removed.
