Status legend: CANDIDATE-PASS = implemented + evidenced in this candidate;
E8.1 is a process gate and stays PENDING (no implementation can assert it).

E1 — Export read-only (zero writes)
  E1.1 CANDIDATE-PASS  Export (JSON+CSV) × all 3 ranges performs zero repository write calls.
                       Evidence: PortableExportServiceTest
                       "every format and range performs zero repository writes and preserves
                       the snapshot" (counting double + write-failure double: any write would
                       throw; writeCalls == 0; insert/update/delete == 0).
  E1.2 CANDIDATE-PASS  Source data unchanged (snapshot before/after equality, revisions intact).
                       Evidence: same test (`before == repository.snapshot()`).

  E2.2 CANDIDATE-PASS  CSV v1 schema: exact 16-column header, header-only empty export,

  E2.3 CANDIDATE-PASS  Import failure matrix (missing/wrong schema; missing/non-integer/other/
                       future version; unknown fields top-level + event + extras; duplicate keys
                       at top-level/event/extras levels incl. escaped-key collisions; malformed
                       JSON; invalid UUID; invalid enums; non-finite numbers; NaN/Infinity
                       literals; invalid local_date/zone_id/actual_time; wrong types; over-size;
                       over-count) -> typed failure + zero writes.
                       Evidence: PortableJsonStrictDecoderTest (15 tests covering ~30 cases);
                       PortableImportServiceTest ("invalid documents and unsupported versions are

  E2.4 CANDIDATE-PASS  Legacy Mahiro compatibility-regression: no-meta documents accepted;
                       unrelated meta.version tolerated and NOT a canonical gate; unknown fields

  E2.5 CANDIDATE-PASS  CSV medication mapping exhaustive per Table D (6 non-AA routes × 5 esters;
                       ANTIANDROGEN ordinals 0–3; unknown/non-integral/out-of-range/missing ->

  E2.6 CANDIDATE-PASS  Cross-format negative: a valid canonical document submitted to the legacy
