v1.7.4 settled navigation motion — correction baseline
=======================================================

Baseline: bcb12d432af1e9780e66686359545e69a056da39 (released v1.7.3).
Original candidate: c8f5edff3c9fa571b82c88efa89ae2cce8ae9bd4.

Independent review: REQUEST_CHANGES V1.7.4 SETTLED MOTION.
P1: AppNavigation mutated RouteEdgeTracker from a remember(currentRoute)
initializer, so an abandoned/restarted composition could advance the tracker
without a successful UI commit.

The correction preserves the existing settled-motion architecture and changes
only edge lifecycle semantics: preview is pure during composition; commit runs
from SideEffect after successful composition.
