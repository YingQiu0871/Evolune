EVOLUNE v1.8.0 D-13 — SEMANTIC EQUALITY EVIDENCE
================================================

Method: for every cardinality, the BASELINE set stores SHA-256 digests of the
exact result rows (all columns, in returned order) for four reference queries;
every candidate set (A/B/C/C3) at the SAME cardinality recomputes the digests
and must match EXACTLY (same rows, same contents, same order, same bounds,
same null behavior). Fixture re-seeding is deterministic (stable ids/timestamps)
so row content is identical across sets by construction; any digest mismatch
would indicate a semantic difference, not fixture noise.

Reference queries (medium windows + recent20 + allHistory mid):
  localDateRange  2025-01-05..2025-01-25 inclusive (null-localDate excluded)
  occurredAtRange [day4, day20) half-open
  recent20        ORDER BY occurredAt DESC, id ASC LIMIT 20
  allHistory      occurredAt <= day15 inclusive
