# 追踪日期小组件（Anchor/Tracked Date Widget）功能规格

## 功能名称

追踪日期小组件（Anchor/Tracked Date Widget）

该小组件是一种独立的桌面小组件类型，与服药进度小组件并列。它专门用于将用户记录的某一个"追踪日期"（如重要纪念日、开始日期等）固定显示在主屏幕上，让用户随时查看该日期距今的天数或相关信息。

---

## 用户入口

1. 用户在系统主屏幕（Launcher）上长按空白区域，进入"添加小组件"界面。
2. 在应用小组件列表中找到该应用的"追踪日期"小组件类型，将其拖拽放置到主屏幕。
3. 放置后，系统立即打开全屏配置界面。
4. 对于已放置的小组件，用户可在 Launcher 上长按该小组件，选择"重新配置"，再次打开配置界面。

---

## 输入/输出

**用户输入：**
- 选择一个已有的追踪日期作为该小组件的"锚点"（Anchor）
- 或在配置过程中新建一个追踪日期
- 选择是否叠加渐变彩旗背景（共 10 个选项：无 + 9 种彩旗）
- 调整外观参数：配色色调、饱和度、明暗平衡、内容缩放比例、背景不透明度、深色模式
- 点击"保存"或"取消"

**展示输出：**
- 配置界面顶部显示小组件的实时预览，背景透出设备壁纸
- 预览随外观参数调整实时更新
- 当深色模式设为"跟随系统"时，预览区角落提供日/夜切换按钮，供用户预览两种外观（不改变保存值）
- 保存成功后，主屏幕上的小组件立即刷新，显示所选追踪日期的内容

---

## 用户操作流程

### 首次放置

1. 用户从 Launcher 拖放追踪日期小组件到主屏幕。
2. 系统打开全屏配置界面，顶部显示实时预览。
3. 若用户尚无任何追踪日期：
   - 点击"选择追踪日期"行，直接弹出"新建追踪日期"表单。
   - 填写名称、图标、日期等信息并确认，新日期被创建并自动选中。
4. 若用户已有一个追踪日期：
   - 该日期被自动选中，用户可直接调整外观后保存。
5. 若用户已有多个追踪日期：
   - 点击"选择追踪日期"行，弹出追踪日期选择列表。
   - 从列表中选择一项，弹窗关闭，所选日期显示在配置行中。
6. 用户可展开"渐变彩旗"选项（点击该行使其展开/折叠），从色块网格中选择一种彩旗或选"无"。
7. 用户调整外观参数（滑块和深色模式选项），预览实时响应。
8. 点击"保存"：
   - 系统将所选追踪日期与外观写入持久化存储。
   - 配置界面关闭，主屏幕小组件立即刷新。
9. 点击"取消"或按返回键：
   - 小组件从主屏幕移除（因配置未完成，等同于取消放置）。

### 重新配置已有小组件

1. 用户长按已有的追踪日期小组件，选择"重新配置"。
2. 配置界面打开，显示该小组件当前保存的外观和所选追踪日期。
3. 操作流程与首次放置相同，但"取消"不再移除小组件——小组件保持原配置不变。

---

## 状态变化

| 状态 | 描述 |
|------|------|
| 待配置（首次放置） | 小组件已添加到主屏幕，正在等待用户完成配置。若用户取消，小组件被移除。 |
| 已配置 | 用户完成选择并保存后，小组件显示所选追踪日期内容。 |
| 锚点悬空（Dangling） | 所选追踪日期在 App 内被删除，小组件进入空内容状态，不显示有效数据。 |
| 重新配置中 | 用户正在为已有小组件更改设置，期间主屏幕上的小组件保持当前外观。 |

**"保存"按钮状态：**
- 在追踪日期小组件配置界面，若尚未选择任何追踪日期（包括锚点已悬空的情况），"保存"按钮保持禁用，无法点击。
- 选中有效追踪日期后，"保存"按钮启用。

---

## 数据字段的业务含义

| 字段 | 含义 |
|------|------|
| 追踪日期（锚点） | 用户记录的某个有意义的日期，例如"开始用药日期""纪念日"等。每个追踪日期有唯一标识、名称、图标、日期及可选调色盘标签和置顶排序。 |
| 渐变彩旗背景 | 可选的视觉装饰层，叠加在小组件卡片背景上，提供自我表达的彩旗图案（如彩虹旗、跨性别旗等共 9 种，外加"无"）。 |
| 配色色调 | 小组件主题色的色相，可手动指定（0°-359°）或设为"动态"（跟随系统壁纸提取色）。 |
| 饱和度 | 小组件配色的色彩浓度，0%-100%。 |
| 明暗平衡 | 小组件配色的明暗偏移，以中点为基准，可向亮或暗方向调整（显示为 -50 至 +50）。 |
| 内容缩放 | 小组件内文字和图标的整体缩放比例，50%-150%。 |
| 背景不透明度 | 小组件卡片背景的透明程度，50%-100%。 |
| 深色模式 | 控制小组件使用浅色外观、深色外观，还是跟随系统主题。 |

所有外观参数（包括配色色调、饱和度、明暗平衡、内容缩放、背景不透明度、深色模式）均为全局共享设置，修改后对该应用所有小组件类型（追踪日期小组件和服药进度小组件）统一生效；追踪日期锚点选择和背景渐变旗帜为每个小组件实例独立配置。

---

## 边界情况

- **无追踪日期时放置小组件**：配置界面的"选择追踪日期"行打开的是"新建追踪日期"表单，而非选择列表。新建完成后，新日期被自动选中。
- **仅一个追踪日期**：配置界面打开时自动选中该唯一日期，用户可直接保存，无需手动选择。
- **多个追踪日期**：需用户手动从选择列表中选择，不自动预选。
- **已有选中，后列表变为单条**：若自动选中逻辑检测到当前无选中且列表仅剩一项，则自动补充选中；若当前已有选中，则不覆盖。
- **配置界面被系统杀死后重开**：界面重新从持久化存储加载已保存的外观和锚点 ID，不会以默认值覆盖已存储的设置。
- **同一配置界面切换到不同小组件**：当 Launcher 在同一个配置界面实例上触发对另一个小组件的配置时，界面在原地切换目标，之前的选择被丢弃，重新从新目标小组件的已保存状态加载。

---

## 错误状态

- **锚点悬空**：所选追踪日期在 App 内被删除后，若用户重新打开配置界面，选择行显示为未选中状态，"保存"按钮禁用。用户必须重新选择一个有效日期才能保存。小组件本身在主屏幕上显示为空内容。
- **数据加载失败**：配置界面若无法从存储中读取已保存设置（如存储异常），界面会自动关闭，不会以错误默认值填充表单后让用户意外覆盖真实设置。
- **保存写入失败**：若外观写入失败，小组件本身仍被视为已配置（Launcher 收到成功信号）；若锚点 ID 写入失败，则配置视为失败，首次放置的情况下小组件被移除（Launcher 收到取消信号）。
- **App 锁**：若用户启用了应用锁（生物识别或 PIN），配置界面在验证通过前不显示任何内容（追踪日期名称等隐私数据）。显示锁定屏幕，要求用户解锁。

---

## 离线/重启后的行为

- 小组件外观设置和锚点选择均持久化到本地存储，设备重启后无需重新配置。
- 重启后小组件会在系统就绪时自动刷新，显示当前追踪日期内容。
- 无需网络连接，所有数据均来自本地。
- 若追踪日期数据库在冷启动时加载缓慢，配置界面会等待数据库就绪（有超时限制）；超时后以最近的快照数据填充列表，避免无限空白等待。数据库恢复后，列表会自动更新。

---

## 可观察的同步行为

- 当用户在 App 内新增追踪日期时，已打开的小组件配置界面的追踪日期列表会实时更新，新增的日期立即出现。
- 外观参数的改动会实时反映在配置界面的预览中（滑块拖动期间连续更新）。
- 保存成功后，主屏幕上的小组件立即刷新，不需要用户手动触发。

---

## 与其他功能的关系

- **追踪日期（Journal 功能）**：小组件显示的内容来源于 App 内"追踪日期"列表。用户必须至少拥有一个追踪日期才能完成配置（可在配置时新建）。
- **服药进度小组件（中型/大型）**：外观参数（色调、饱和度、明暗、缩放、透明度、深色模式）是全局共享的，修改任意一个小组件的外观会影响所有小组件。追踪日期锚点为独立的每实例配置。
- **应用锁**：若启用了应用锁，配置界面与主应用一样需要身份验证才能访问。
- **App 内追踪日期管理**：若用户在 App 内删除了某个追踪日期，已使用该日期配置的小组件进入悬空状态；下次重新配置时，用户必须重新选择。

## 独立实现所需的验收测试列表（描述性，不含代码）

1. **首次放置 - 无追踪日期**：从 Launcher 添加小组件，验证配置界面打开"新建追踪日期"表单；填写并确认新建，验证新日期被自动选中，"保存"按钮变为可点击。

2. **首次放置 - 仅一个追踪日期**：添加小组件时账户内恰好有一个追踪日期，验证配置界面打开后该日期已自动选中，无需用户手动操作即可保存。

3. **首次放置 - 多个追踪日期**：有多个追踪日期时添加小组件，验证配置界面无预选，"保存"按钮禁用；用户手动选择一个后，"保存"变为可用。

4. **取消首次放置**：在配置界面点击"取消"或按返回键，验证小组件从主屏幕移除（Launcher 未收到"已配置"的成功信号）。

5. **重新配置 - 取消不改变**：对已配置的小组件重新配置，在未保存的情况下取消，验证主屏幕上的小组件内容和外观不变。

6. **锚点悬空后重新配置**：在 App 内删除某个已被小组件使用的追踪日期，打开该小组件的配置界面，验证选择行显示未选中状态，"保存"按钮禁用；重新选择一个有效日期后，"保存"恢复可用并可成功保存。

7. **渐变彩旗选择与预览**：展开渐变彩旗选项，选择一种彩旗，验证预览立即更新为对应彩旗背景；选择"无"，验证预览恢复无背景。

8. **外观参数实时预览**：拖动各外观滑块，验证预览在拖动过程中持续更新，不出现长时间空白或画面冻结。

9. **深色模式预览切换**：将深色模式设为"跟随系统"，验证预览区出现日/夜切换按钮；点击按钮，验证预览在浅色和深色间切换，但该切换不影响最终保存值。

10. **保存后主屏幕立即刷新**：选择追踪日期并保存，验证配置界面关闭后主屏幕上的小组件立即显示所选日期内容，无需等待或手动刷新。

11. **外观全局共享**：调整某一小组件的外观参数并保存，验证其他同类小组件的外观也同步更新；追踪日期锚点选择不影响其他小组件。

12. **数据加载失败时不崩溃**：模拟存储读取失败，验证配置界面自动关闭而非显示空白或错误表单。

13. **应用锁验证**：在启用应用锁的情况下打开配置界面，验证在通过身份验证之前不显示追踪日期列表或任何数据；通过验证后，正常显示。

14. **配置后重启恢复**：配置并保存小组件，重启设备，验证小组件重启后自动恢复显示正确内容，无需重新配置。
