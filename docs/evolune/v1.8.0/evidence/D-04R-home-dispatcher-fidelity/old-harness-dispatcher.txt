OLD D-04 HARNESS DISPATCHER TOPOLOGY

The committed D-04 temporary harness constructed Home HRTViewModel with:
  operationScope = CoroutineScope(SupervisorJob() + Dispatchers.Default)
  simulationDispatcher = Dispatchers.Default

Therefore its outer collectLatest operation scope and its inner simulation context had the
same effective Default dispatcher. The harness did not execute the production Main.immediate
caller -> Dispatchers.Default simulation -> Main publication-return path.

The old controller also released the superseded generation before invoking SimulationEngine.run
inside its runner. Its T2 therefore was not a proof that the engine was already executing when
supersession occurred. The old repeated trace is valid as a Default-to-Default control artifact,
but not as production Home dispatcher evidence.
