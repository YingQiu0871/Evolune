Prior D-04 conclusion:

  ordering. It did not exercise production Main.immediate -> Default -> Main semantics.

  work, actual Main runSimulation() supersession, and actual Main pkState observation, 0/30
  superseded generations produced stale HRT publication. All 30 satisfied T1<T2<T3. The old
  Default-to-Default control produced 24/30 stale publications.

Decision:
  The old Home stale-publication claim is rejected as a dispatcher artifact. M04 engine
  cancellation latency remains separate and is not fixed by this evidence-only correction.
