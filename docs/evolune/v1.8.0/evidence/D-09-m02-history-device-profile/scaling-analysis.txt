EVOLUNE v1.8.0 D-09 — SCALING ANALYSIS
======================================

Projection (P6) Main CPU medians:
  100 events /3 plans  (34-102 occ):    6.2 ms
  1000 events/1 plan   (34 occ):       19.3 ms
  1000 events/3 plans  (102 occ):      44.3 ms
  1000 events/8 plans  (272 occ):     108.8 ms
  10000 events/3 plans (102 occ):     385.3 ms

Relationships:
- Event scaling at fixed density (3 plans): 100 -> 1000 -> 10000 events gives
  6.2 -> 44.3 -> 385.3 ms, i.e. roughly linear in events (x7.1 and x8.7 per
  decade; some superlinearity at high counts).
- Plan-density scaling at fixed 1000 events: 1 -> 3 -> 8 plans gives
  19.3 -> 44.3 -> 108.8 ms, i.e. roughly linear in generated occurrences
  (34 -> 102 -> 272; ratios 2.3x and 2.5x vs occurrence ratios 3x and 2.7x).
- Combined: cost follows the matcher's event x occurrence interaction observed
  by D-02, now quantified on-device.
- Queries and mapping grow much more slowly (query wall 6.4 -> 69.4 ms from
  100 to 10000 events; mapping CPU 1.6 -> 18.3 ms) and remain the minority of
  the load at every scale.
- Grouping (P7) is negligible (0.2-0.5 ms).
- Generation (P2) is small (0.8-7.8 ms at <=1k; 3.3 ms at 10k).

Extrapolation warning: values beyond the measured points are not asserted. The
10k case is synthetic stress (≈22 events/day in one month) and is used only to
bound the scaling behavior, not as a representative user scenario.
