=== INTERPRETATION =========================================================

1. At representative cardinalities the current unindexed queries are already
   sub-millisecond (median <= 0.78 ms, p95 <= 0.82 ms). Absolute index gains
   are 0.02-0.35 ms per query.
2. Even at 10k STRESS the worst baseline median is 1.73 ms (recent20) and the
   worst p95 is 2.90 ms (OA wide). These are Room-executor wall times, not
   Main-thread blocks (see no-main-thread-conflation.txt).
3. Relative improvements at stress are large (50-93%) precisely because the
   baseline is tiny; the ABSOLUTE user-visible delta stays under 1.7 ms on
   paths that run a few times per user action.
4. For scale comparison: the History projection CPU is 40-150 ms (D-09/D-10
   evidence, worker thread); the query tail these indexes would shave is
   two orders of magnitude smaller than the load's dominant cost.
5. SET C3's direction-specific third index removes the recent20 partial sort
   but improves recent20 by <= 0.007 ms over SET B at 10k and is WORSE than B
   at card 1000 (0.1705 vs 0.1190) — a second occurredAt index is not
   justified.
