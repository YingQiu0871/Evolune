Home current-concentration interpolation

HomeScreen.kt:723-750 implements calculateConcentrationAtTime as follows:

* empty arrays return null;
* minOrNull and maxOrNull each scan the complete time list;
* an out-of-range target returns null;
* an in-range target is found with a forward linear scan and linearly
  interpolated, with an equal-time guard.

For a target in segment k of an ordered N-point result, the source-level scan
work is 2N + (k + 1) element visits (two full range scans plus the forward
search). It is O(N) per current-time update; no binary-search index or retained
segment cursor is used.
